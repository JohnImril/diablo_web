Diablo Web player guide

Play the original Diablo (Diablo 1) in your browser. Start with the free shareware demo, or use your own game data for the full game. Desktop mouse and keyboard work best.

Do I need to own Diablo?

Play Free Demo downloads the limited shareware version on first use (about 25–50 MB). It needs no purchase or local MPQ. The full game requires your own DIABDAT.MPQ from a legal copy of Diablo, available from GOG.

Choose Load Your MPQ, or drop the archive onto the start screen. Retail data is not included. Compression is optional: open Controls, limitations & game files and choose Compress an MPQ to reduce its size.

Mouse, keyboard and touch controls

Input Action

Right click Cast the selected spell.

I / C / B / Q Inventory / character / spellbook / quests.
Tab / Esc Map / game menu or close the current panel.
1–8 Use an item from the corresponding belt slot.

On phones, use landscape and the on-screen mouse/modifier, belt, and function-key controls. Touch controls still need refinement; desktop is the recommended starting point.

Where are my saves?

Saves and cached game files stay in this browser/profile through IndexedDB. There is no cloud sync. Export saves before clearing site data, changing browsers, or moving to another device.

  • Export: open Manage Saves on the start screen and download the saves to keep.
  • First import: if Manage Saves is absent, drop a .sv file onto the start screen. Manage Saves appears after import.
  • More imports: use the upload control in Manage Saves or drop another .sv file.

Keep only one game tab or installed app window open per browser profile. Returning to the menu or switching tabs does not release save storage.

Can I install it or play offline?

The production app supports installation through the browser's install option when available. It caches the app shell and engine assets; the demo archive is stored separately after its first download. Load the game online first and verify it starts before relying on offline access. Multiplayer needs a network.

Updates wait during gameplay and apply on the start screen when other active game tabs allow it. The page waits for storage writes before reloading. If saving fails or times out, reload is blocked and save downloads are offered; keep those backups before retrying.

How do I play with a friend?

Online multiplayer is experimental. Both players need the same client build and game-data mode, and a host configured with the hellgate-ws backend.

  1. Choose Multi Player → WebSocket (Server), then create or select a multiplayer character.
  2. The host chooses Create Game and enters a name, for example tristram-1.
  3. The friend chooses Join Game and enters the same name. Names are case-sensitive; use 1–32 letters A–Z/a–z, digits, underscores, or hyphens.

Up to four players can join. The host leaving closes the room. For two players on one computer, use separate browsers/profiles. WebRTC (Direct) is a separate transport.

Server owners: follow the client connection guide for configuration and troubleshooting. A hosted build may have no multiplayer server configured.

When something goes wrong

  • Game already open: finish saving in the other game, close its tab/app window, then choose Try Again on the blocked page. Do not clear browser data.
  • Loading error: choose Reload and Try Again when offered. If reload is blocked, keep the page open, download the offered saves, and retry.
  • Browser support: enable JavaScript and use a current browser with WebAssembly, Web Workers, IndexedDB, and Web Locks. Open the game over HTTPS or localhost; a plain HTTP LAN address is insufficient.
  • Report a bug: the error dialog can open a GitHub issue draft and download diagnostics. Review the draft before submitting. Save backups are separate downloads and are not automatically uploaded.
